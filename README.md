# Offline Android POS & Invoice Manager

**Offline Android POS & Invoice Manager** is a native Android application designed for small retail businesses, service providers, and shops that need a reliable billing and sales management system without depending on an internet connection or cloud server.

## Key Features

- 🧾 Create and manage sales invoices
- 🛒 POS interface for products, services, and liquid/fuel items
- 📦 Product and service catalog management
- 💰 Flexible pricing with inline rate override
- 💳 Payment and transaction recording
- 📊 Sales reports and transaction history
- 🔎 Search, filtering, sorting, and pagination
- 📥 XLSX data import
- 📤 XLSX data export
- 🖨️ Bluetooth ESC/POS thermal printing
- 🧾 58mm and 80mm receipt support
- 📄 PDF invoice/receipt generation
- 🏪 Custom company header and logo
- 🔢 Accurate paisa-based financial calculations
- 🌐 Bangla and English language support
- 🌙 Light and Dark mode
- 📈 Sales graphs and visualization
- 💾 Fully offline local database

## Technology Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- Room Database
- SQLite
- Coroutines & Flow
- Bluetooth ESC/POS
- XLSX Import/Export
- PDF Generation

## Offline-First

The application is designed to work completely offline.

It does not require:

- Internet connection
- Cloud database
- External API
- Backend server
- User authentication

All essential POS, invoicing, reporting, and data management operations are handled locally on the Android device.

## Purpose

This project demonstrates the development of a practical offline POS and invoice management solution using modern Android technologies, with a focus on reliable local data management, accurate financial calculations, thermal printing, and a simple user experience.
